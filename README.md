# Bishal Roy academic website

Static multi-page site for GitHub Pages.

## Pages
- `index.html` - Home: education, experience, all CV awards, service/training
- `research.html` - Research, research awards, all publications, technical scope
- `teaching.html` - Teaching experience, instructional areas, teaching/communication recognition
- `cv.html` - Embedded academic CV with open/download links

## Existing assets that must remain in your repository
Do not rename these files:
- `assets/Bishal_Roy_CV.pdf`
- `assets/headshot.jpg`
- `assets/field_uav.jpg`

## Replace / add
Upload these files from this package:
- `index.html`
- `research.html`
- `teaching.html`
- `cv.html`
- `assets/css/site.css`
- `assets/js/site.js`
- `assets/icons.svg`

If `publications.html` exists from an earlier version, delete it. Publications now live in `research.html`.

## GitHub Pages
Keep the Pages source set to the repository root on the `main` branch. No build step, framework, package manager, or configuration file is required.
